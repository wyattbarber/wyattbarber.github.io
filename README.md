## Master's Thesis

<div style="display: flex; gap: 20px;">

<div style="flex: 1;">

<img src="/assets/img/drone-perched.jpg" alt="Failed to Load Image">

</div>

<div style="flex: 1;">

My master's thesis aims to develop an image processing method for detecting objects that
a drone can perch from, and a grasping mechanism which can attach a drone to such objects.
A drone equipped with such a device could find use in inspecting infrastructure such as power lines,
performing environmental data collections in difficult to reach places, or establishing emergency sensor and
communication networks during disaster response.  
<br>
<br>
The code used to implement image processing and grasper control functions
can be found <a href="https://github.com/wyattbarber/PerchDetector">here</a>.
<br>
<br>
For OpenSCAD scripts and KiCAD files used in the hardware design for this project,
look <a href="https://github.com/wyattbarber/Thesis-Design">here</a>.

## Tree Modeling

<div style="flex: 1;">

This project, done as a semester capstone during my master's coursework, developed an image processing method to generate graph-like 
representations of trees from RGB images. Such a tool could find use in automated pruning robots, where
connectivity of the branches in view must be analyzed to determine pruning locations. The project assessed
reconstruction accuracy of the method in 2D test images.

<br>
<br>

The code and term paper for this project can be found <a href="https://github.com/wyattbarber/EGR-600-Semester-Project">here</a>.
